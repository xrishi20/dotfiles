Installation
```bash
tar -xvf visioncursorwhite.tar.gz    	       # extract `visioncursorwhite.tar.gz`
mv visioncursorwhite ~/.icons/        	       # Install to local users
sudo mv visioncursorwhite /usr/share/icons/    # Install to all users
```

Uninstallation
```bash
rm ~/.icons/visioncursorwhite                  # Remove from local users
sudo rm /usr/share/icons/visioncursorwhite     # Remove from all users
```
