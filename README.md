# Configuration

### SSH Permissions

```
chmod 700 ~/.ssh
chmod 600 ~/.ssh/*
```

### Git Configs

```
git config --global alias.a "add ."
git config --global alias.cm "commit -m"
git config --global alias.puo "push -u origin"
```
```
git config --global user.name ""
git config --global user.email ""
```

### SDDM Configuration

```
sudo nano /etc/sddm.conf
```
